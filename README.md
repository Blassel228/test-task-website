
## 🖼️ Required Image Assets

To ensure the application displays correctly, you must add the following image files to your `Assets` folder:
Assets/
├── hotel1.jpg
├── hotel2.1.jpg
├── hotel2.2.jpg
├── hotel2.3.jpg
├── moreno.jpg
├── icon.png
├── san-francisko.jpg
├── vacation1.jpg
├── vacation2.jpg
└── villa.jpg

Run npm install 
Then run npm run dev
You are ready to go
